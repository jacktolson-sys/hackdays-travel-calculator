Welcome & Introduction
Script Good [morning / afternoon], everyone. Thank you for joining us today. My name is [Name], and I'm on the Channel Marketing team here at Geotab. We've been working on something that I think is going to save a lot of time and guesswork when it comes to planning our Hackdays events — and I'm excited to walk you through it today.
Presenter Tip Introduce yourself and anyone else presenting with you. Make eye contact and keep the opening warm — this is an internal tool, so the tone should be conversational.
2
The Problem We're Solving
Script Planning a Hackdays event across multiple cities and time zones means dealing with a lot of moving parts: flight costs, hotel rates, venue options, food and beverage budgets, and the constant back-and-forth of pulling numbers from different sources. Up until now, a lot of this lived in spreadsheets, inboxes, and people's heads. We wanted to create something that brings it all together in one place — so that anyone on the team can build a realistic budget quickly, without having to start from scratch every time.
Presenter Tip Pause after this slide to let the problem land. You can invite a quick "does that sound familiar?" to the audience before moving on.
3
Tool Overview
Script What we've built is a two-part web tool. The first part is the Travel Cost Breakdown — it lets you input attendees, select flight origins, estimate hotel nights, and capture trip expenses to produce a full per-person and total event budget in seconds. The second part is the Event Planner — where you can build a shortlist of venues and restaurants, compare costs, and generate a polished proposal slide deck to share with your team or stakeholders. Both tools run entirely in the browser — no login, no installation required.
Presenter Tip Show the landing page here. Click between the two tabs in the nav bar so the audience can see the two tools side by side.
4
Travel Calculator — Attendees & Flights
Script Let's start with the Travel Calculator. On the left side you'll see the Attendees and Flights panel. You enter the number of people attending, choose a destination city, and then fill in where each person is flying from. The tool uses a distance-based model to estimate the roundtrip flight cost for each origin — and the numbers are pulled from a live Google Sheet that gets updated automatically, so they reflect current pricing conditions rather than stale hardcoded values.
Presenter Tip Live-demo this: enter 15 people, select a destination like Chicago, IL, and add a few origin cities. Let the audience watch the cost column populate in real time.
5
Flight Search Integration
Script Once you've entered your event dates, each attendee row gets a direct flight search button. Clicking it opens Skyscanner with the origin, destination, and dates pre-filled — so instead of copy-pasting information into a third-party site, you go straight from the tool to a live price comparison in one click. This saves time during planning and gives coordinators a quick sanity-check on estimates.
Presenter Tip Click the flight search button live to show how it opens Skyscanner. Make sure event dates are filled in first or the link won't include dates.
6
Hotel Cost Estimation
Script The next section handles hotel costs. You enter the number of hotel nights required, and the tool automatically pulls in a per-night rate for the selected destination city. These rates come from the same live Google Sheet — updated daily using a tiered pricing model that accounts for the city, the time of year, and the current Canadian dollar to US dollar exchange rate. There's a disclaimer at the bottom reminding users that these are estimates — the tool is designed for budgeting, not booking.
Presenter Tip Point out the light blue disclaimer. This is intentional — we want planners to use it as a starting point, not a confirmed quote.
7
Trip Details & Miscellaneous Costs
Script On the right side you have the Trip Details panel. This is where you enter the event dates, ground transportation estimates, per-day meal allowances, and any additional committed costs like AV equipment, signage, or SWAG. There's an information icon on the Miscellaneous Costs section — hovering over it explains that this is where you'd capture pre-approved budget lines or additional funding that's already been secured for the event.
Presenter Tip Hover over the info icon on "Additional / Miscellaneous Costs" to show the tooltip. It's a small detail, but it reassures the audience that the tool is well-documented.
8
Budget Summary & Export
Script As you fill in the fields, the Budget Summary at the bottom updates in real time. You can see the total per person, the total event cost, and a line-by-line breakdown of how the budget is made up. When you're ready to share, you can export the full summary to an Excel spreadsheet with one click — formatted and ready to drop into a budget approval request or hand off to finance.
Presenter Tip Click "Export to Excel" live and let it download. Open the file briefly if you can — it reinforces how polished the output is.
9
Event Planner — Overview
Script Now let's look at the Event Planner. This is where you move from "how much will it cost to get everyone there" to "what are we actually doing once we arrive." You start by entering the event city, the event date, start time, and the number of guests. Then you build a list of venue and restaurant options — so you can compare them side by side before making a final recommendation.
Presenter Tip Navigate to event-planner.html and fill in the event header fields before the demo so the audience sees a realistic scenario, not blank fields.
10
Adding Venues & Restaurants
Script Adding a venue is straightforward. You enter the venue name, select whether it's a venue, restaurant, or bar, enter the capacity, the venue fee, and the food and beverage budget. You can paste in a link to the venue's website and their food menu — these links become clickable in the final proposal. There's also an atmosphere description field, with an auto-fill button that generates a starter description based on the name, type, and city — which you can then edit to match the actual vibe of the space.
Presenter Tip Live-add one venue. Use the Auto-fill button on the description — it generates a placeholder in seconds, which tends to get a good reaction from the audience.
11
Proposal Generation
Script Once you've added your venues, you can generate a PowerPoint proposal with one click. The deck includes a title slide with the event date, time, and guest count, followed by one slide per venue — covering the atmosphere description, capacity, pricing, and direct hyperlinks to the website and food menu. This is something you can send directly to a stakeholder or manager to get sign-off on the venue shortlist — no additional formatting needed.
Presenter Tip Click "Generate Proposal" and open the downloaded .pptx. Click a hyperlink to show that the website and menu links are live and clickable inside the deck.
12
Live Data & Spreadsheet Integration
Script Under the hood, both flight and hotel rates are powered by a Google Sheet that the team maintains. Flight costs are calculated using a distance model with a live CAD-to-USD exchange rate. Hotel rates are updated every morning by a scheduled Google Apps Script that applies seasonal pricing factors. The website reads directly from that sheet, so the numbers stay current without anyone having to manually update the tool.
Presenter Tip You don't need to go deep on the technical details here — most audiences just want to know the data doesn't go stale. Keep this slide conversational and brief.
13
How to Use It — Step by Step
Script Here's the quick-start flow for anyone using the tool for the first time. Step one: open the Travel Calculator and enter your event details — destination, attendees, dates. Step two: review the budget summary and export to Excel if you need to share it with finance. Step three: open the Event Planner, enter your event information, and add your venue shortlist. Step four: generate the proposal and share the .pptx file with your stakeholders. There's a User Guide linked in the top right corner of both pages if anyone needs a walkthrough.
Presenter Tip This slide is great to leave up during Q&A as a visual summary. Point to the User Guide link on screen so people know where to find help after the presentation.
14
Q&A & Next Steps

We built this to make event planning faster, more consistent, and easier to share — and we're continuing to improve it based on feedback from the team. If you have questions about how it works, how to access it, or ideas for what you'd like to see added, we'd love to hear them. I'll drop the link to the tool in the chat so you can try it yourself after this call.
Presenter Tip Have the tool URL and the User Guide URL ready to paste into the chat. Thank the audience, and if time allows, do a short live Q&A where you demo anything they ask about directly in the browser.
